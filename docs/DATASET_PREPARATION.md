# Dataset Preparation

This project expects the BEHAVIOR-1K challenge demonstrations at
`datasets/2025-BEHAVIOR-1K-CHALLENGE` under the SERF-VLA project root. This
matches `behavior_dataset_root` in `src/serf_b1k/training/config.py`.

## Download Task Demonstrations

You can download only the task demonstrations needed for your experiments from
the HuggingFace dataset repository.

⚠️ You must replace `[YOUR_HF_TOKEN]` with your HuggingFace access token.

```bash
cd BEHAVIOR-1K
uv run python - <<'PY'
from huggingface_hub import snapshot_download

target_tasks = ["0009", "0021", "0026"]
allow_patterns = [f"*task-{task}*" for task in target_tasks] + ["*.md"]

print(f"Downloading tasks: {target_tasks}")
print(f"Patterns: {allow_patterns}")

snapshot_download(
    repo_id="behavior-1k/2025-challenge-demos",
    repo_type="dataset",
    local_dir="../datasets/2025-BEHAVIOR-1K-CHALLENGE",
    local_dir_use_symlinks=False,
    allow_patterns=allow_patterns,
    token="[YOUR_HF_TOKEN]",
)

print("Download complete.")
PY
```

Update `target_tasks` if you train or evaluate a different task set.

## Prepare SERF Map Dataset

SERF map assets are generated by the separate
[SERF-mapping](https://github.com/ExistentialRobotics/SERF-mapping)
repository. Follow that repository's instructions to build and export neural
feature maps for the BEHAVIOR-1K tasks you want to train or evaluate.

This repository expects the exported map files at:

```text
datasets/
  SERF-BEHAVIOR-1K-MAP/
    exported_neural_points/
      task-0021/
      task-0022/
      task-0026/
    map_models/
      task-0021/
      task-0022/
      task-0026/
```

The expected paths match the defaults used by the SERF configs:

- `map_dataset_root_path="datasets/SERF-BEHAVIOR-1K-MAP"`
- `robot_model_root_path="datasets/SERF-BEHAVIOR-1K-MAP/map_models"`

The `exported_neural_points` directory is used by 3D and 4D environment-map
policies. The `map_models` directory is additionally required for
`4d_env_robot_feat_map` policies because it contains the robot map assets.
